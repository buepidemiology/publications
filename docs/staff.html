Missing publications? Import them from Google Scholar

This page only shows works on your ORCID record. You can copy your whole Google Scholar list into ORCID in a few minutes. Import everything: ORCID groups works it already has, and this site shows each publication only once, so you don’t need to compare the two lists first.

  1. Open your Google Scholar profile. Scroll down and click Show more until every publication is listed.
  2. Tick the checkbox at the top of the list to select all, then choose Export → BibTeX. A page full of text opens in your browser.
  3. Save that page as a file: press Ctrl + S (Windows) or Cmd + S (Mac) and save it as a .txt or .bib file.
  4. Sign in to ORCID. In the Works section, choose Add → Import BibTeX and select the file you saved.
  5. Look over the list. Google Scholar sometimes includes papers by someone else with a similar name, so remove any that aren’t yours. Then save the rest.
  6. Make sure the works’ visibility is set to Everyone. Private works can’t be seen by this site.
